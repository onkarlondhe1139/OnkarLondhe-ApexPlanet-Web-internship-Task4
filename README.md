# Task 4 - Full Project Implementation

## Objective

The goal of Task 4 is to combine **HTML, CSS, and JavaScript** to build fully functioning front-end projects. This submission includes three separate mini-projects inside one structured folder:

1. A **Personal Portfolio Website**
2. A **To-Do List App with Local Storage**
3. A **Product Listing Page with Filtering and Sorting**

## Project Overview

This project set demonstrates core front-end development skills such as:

- Semantic HTML structure
- Responsive CSS styling
- JavaScript DOM manipulation
- Data persistence using `localStorage`
- Interactive filtering and sorting logic

## Included Projects

### 1. Personal Portfolio Website

A responsive multi-page portfolio website designed to present profile information in a professional format.

#### Pages

- `About`
- `Projects`
- `Contact`

#### Features

- Multi-page navigation
- Shared styling across all pages
- Responsive layout for desktop, tablet, and mobile
- Clean and professional design
- Contact form demo with JavaScript feedback

### 2. To-Do List App with Local Storage

A task management application that allows users to add and manage tasks with persistent browser storage.

#### Features

- Add new tasks
- Assign task priority
- Mark tasks as completed
- Delete tasks
- Filter tasks by status
- Clear completed tasks
- Save and retrieve tasks using `localStorage`

### 3. Product Listing Page

A product catalog interface built with filtering and sorting functionality for a better browsing experience.

#### Features

- Search products by keyword
- Filter by category
- Filter by price range
- Sort by rating
- Sort by price
- Sort by product name
- Responsive product card layout
